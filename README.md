# Website Chatbot Project

A simple retrieval-based chatbot for commercial websites, deployed on AWS EC2 with Flask and Nginx.


## Features

- Predefined response patterns for common customer inquiries
- Simple web interface with clean design
- Easy to customize responses and patterns
- Deployable on AWS EC2 or any Linux server
- Lightweight and fast response times

## Prerequisites

- Python 3.8+
- AWS EC2 account (for deployment)
- Basic Linux command line knowledge
